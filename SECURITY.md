# Security Policy

PopPiP is built to run locally on your Mac and does not require a backend, account, or remote telemetry pipeline. Because this project is intentionally privacy-focused, we ask that security reports be handled privately.

## Reporting a vulnerability

Please report suspected vulnerabilities via GitHub Security Advisories for this repository.

If GitHub Security Advisories are not available for your case, do not open a public issue containing details that could help an attacker. Instead, share the report through the repository's private reporting path or contact the maintainer directly through the project's GitHub profile.

## What to include

- affected version or commit
- macOS version and Safari version
- steps to reproduce
- expected behavior
- actual behavior
- screenshots, logs, or proof-of-concept if relevant
- any suspected impact or attack scenario

## Response expectations

We will review reports as quickly as possible and coordinate disclosure in a responsible way. Please do not disclose the issue publicly until we confirm the fix or agreed disclosure plan.
