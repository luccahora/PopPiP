# Mac App Store Metadata Draft

**App Name:** PopPiP  
**Subtitle:** Automatic PiP for Safari  
**Promotional text:** Switch tabs. Keep watching.

**Short description:** PopPiP automatically keeps your Safari videos visible in Picture-in-Picture when you switch tabs or apps.

## Description

PopPiP makes Picture-in-Picture feel like a natural part of Safari. Start a
video, switch tabs or move to another app, and PopPiP keeps it visible in a
compact floating window. Return to the video and PopPiP restores the normal
view when it was responsible for starting PiP.

Choose exactly where PopPiP works. Enable individual websites, use Safari's
native website access controls, and optionally turn on PiP when a playing video
leaves the visible page area.

PopPiP is private by design. It has no accounts, analytics, telemetry,
advertising, subscriptions, or backend. Settings stay on your Mac and the app
makes no automatic network requests. The complete source code is publicly
available for inspection and local builds.

PopPiP is a one-time purchase with no subscription.
