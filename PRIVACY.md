# PopPiP Privacy Policy

PopPiP is designed to work entirely on your Mac.

PopPiP does not collect personal data or browsing history. It does not record
sites you visit, identify videos, send URLs, inspect cookies or form contents,
or transmit page content. It has no analytics, telemetry, advertising,
accounts, backend, or external crash reporting. PopPiP does not sell or share
data and makes no background network requests.

The extension examines only HTML `<video>` elements and their playback and
layout state so it can select a playing video and control Picture-in-Picture.
Safari website access is required for that local operation. Safari lets the
user grant or revoke access for each website.

Settings, including enabled hostnames, are stored locally with the extension's
`browser.storage.local` API. They are never synchronized to a server.

Opening a GitHub or support link from the host app is always an explicit user
action and opens the selected page in the default browser.

PopPiP currently uses no tracking domains and declares no collected data.
